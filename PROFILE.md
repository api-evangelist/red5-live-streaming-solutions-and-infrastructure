## APIs

- **Red5 Pro Server API** — REST/JSON API embedded in the Red5 Pro media server providing server info/ping/statistics, applications, streams, recorded content (VOD), shared objects, client control, and log access. Base URL is instance-specific (http://{host}:5080/api/v1/); authenticated via static access token plus IP allowlist. (`http://{host}:5080/api/v1/`)
- **Stream Manager 2.0 API** — REST/JSON API used by both Red5 Pro clusters and Red5 Cloud for Auth, Admin, Proxy, Streams, Streams Provision, Streams Mixer, and Scheduling NodeGroups. Base URL is instance-specific ({streamManagerHost}/as/v1/). Auth via Basic login returning a JWT bearer token. Ships an OpenAPI/Swagger UI per instance at {streamManagerHost}/swagger-ui.html. (`https://{streamManagerHost}/as/v1/`)
- **Red5 Agent-Native Surface** — Publicly hosted llms.txt providing a structured index of Red5 products, use cases, and documentation for AI agents. (`https://www.red5.net`)

> REST APIs (Red5 Pro Server API and Stream Manager 2.0 API) are real and documented but run on customer-deployed/self-hosted instances or the managed Red5 Cloud, not a single vendor-hosted public gateway; base URLs are instance-specific. The OpenAPI/Swagger contract exists but is served per-instance at {streamManagerHost}/swagger-ui.html and can be exported to Postman, so no fixed public spec URL is cataloged.
